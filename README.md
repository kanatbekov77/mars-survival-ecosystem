# MARS: Survival Ecosystem

Проект браузерного научного тренажёра о работе марсианской базы для NASA Space Apps Challenge 2026. Игрок сопровождает экипаж через 30 солов, управляет энергией и жизнеобеспечением и готовит базу к прибытию припасов.

- [Техническое задание проекта](MARS-TZ.md) — рамки, правила, сценарий, зоны работы и приёмка.
- [Game Design Document](MARS-GDD.md) — стартовый CONFIG, модель, все миссии и события, научные карточки и схемы данных.
- [Задание для Claude](CLAUDE-IMPLEMENTATION.md) — интерфейс, аудит, интеграция и тестирование.
- [Сверка ТЗ, GDD и науки](docs/AUDIT.md) — расхождения и рабочие решения D1–D12.
- [Отчёт интеграции](docs/REPORT.md) — тесты, баланс 200 seed, прогон кампании, проверки в браузере, пробелы.

## Играть

- **В браузере по ссылке (ожидаемый адрес, ещё не проверен):** https://kanatbekov77.github.io/mars-survival-ecosystem/ — сайт появится после слияния в `main` и включения Pages (см. ниже).
- **Без интернета:** откройте `dist/mars.html` двойным кликом. Это один файл: стили, код и данные встроены.

Карта базы по умолчанию показана в объёме (псевдо-3D на SVG). Переключатель «Схема / Объём» над картой меняет только вид: ход кампании и открытая панель сохраняются. Список систем под картой открывает любую панель с телефона или клавиатуры.

## Команды (Node ≥ 20, без зависимостей)

```bash
npm run serve      # http://localhost:5173 — исходники как ES-модули
npm test           # 28 тестов: арифметика GDD §12, детерминизм, сохранения, RU/EN
npm run simulate   # баланс: 2 профиля × 5 стратегий × 200 seed
npm run build      # собрать автономный dist/mars.html
```

Клавиши: Space — пауза/пуск, `.` — один тик, 1/2/4 — скорость, L — журнал, Esc — меню паузы. На объекте карты и на кнопках Enter/Space нажимают их.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml`:

- на каждый pull request — `npm test` и `npm run build`, собранная игра прикладывается артефактом `mars-game` (без публикации);
- на push в `main` — те же проверки, затем в артефакт Pages попадает **только** `dist/mars.html` под именем `index.html` (плюс `.nojekyll`), и он публикуется. Если тесты падают, публикации нет.

Один раз владельцу репозитория: **Settings → Pages → Build and deployment → Source → GitHub Actions**. После следующего push в `main` игра откроется по адресу выше. Пока это не сделано и не проверено, адрес считается ожидаемым.

## Структура

- `src/engine/` — чистая детерминированная модель: тик, CONFIG, работы, события, миссии, финалы, сохранения, повтор.
- `src/ui/` — интерфейс поверх команд движка: карта (`isomap.js` — объём, `map.js` — схема и переключатель), HUD, кабинеты систем, решения, разбор.
- `src/i18n/` — русский (основной) и английский.
- `src/data/sources.js` — каталог источников, архивные записи и научные карточки с метками происхождения.

Статус — играбельная первая версия кампании для плейтеста. Числа баланса — проектные допущения; решения на согласование перечислены в отчёте.

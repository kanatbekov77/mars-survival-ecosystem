## 5. Отклонения и оставшиеся пробелы

1. **Исходное ТЗ «Один сол до помощи» недоступно** в этой среде; сверка шла по матрице §1 GDD (AUDIT §6).
2. **Цель компромиссной стратегии 40–60 % не достигнута.** Обе компромиссные политики используют тот же реактивный слой ремонта, что и контрольная, поэтому выживают всегда, но ни разу не достигают устойчивого финала. Нужно согласовать определение «простой компромиссной политики» (например, реакция только утром следующего сола) и после этого настраивать CONFIG.
3. **Один отказ доминирует в поражениях**: 98 % стопов случайной стратегии — E_SCRUB (CO₂). Есть автопауза, 4 тика до тревоги и ~10 до стопа, но это узкие ворота. Предложение на плейтест: показывать кнопку «Переключить на патрон» прямо в окне события.
4. **Тонкий запас воды у Инженера**: медиана минимума 20,8 кг при критерии устойчивости ≥20 кг. Любая дополнительная потеря уводит контрольную стратегию из «устойчивого» финала.
5. **Редис со 2-го сола не успевает к S28**, если LED стояли в бурю (ожидаемо по GDD); в контрольном прогоне собран только салат.
6. Не реализованы: устаревание датчика «2 тика» (есть только смещение E_SENSOR), эффект T_TELEMETRY (тренды показаны всегда), `expectedRunRevision` у команд (одна локальная сессия), IndexedDB (используется localStorage, при ошибке квоты — скачивание JSON).
7. Вне объёма первой версии по ТЗ: Sandbox, ежедневная миссия, картофель, ISRU/BIO, казахский язык, сетевые адаптеры DONKI/OSDR, слой Mars Trek (карта базы — иллюстративный SVG).
8. Не проверено: открытие `dist/mars.html` через `file://` (встроенный браузер не открывает локальные файлы; тот же файл проверен по HTTP без дополнительных запросов); плейтест с детьми и педагогом; длительность демо «до 5 минут».
9. Ветка не отправлена на GitHub и PR не открыт — нужны права и согласие владельца репозитория.
